# Changelog

All notable changes to the PiDbg extension are documented here.

## [0.1.0]

Initial public release.

- Debug .NET applications on a Raspberry Pi over SSH from VS Code.
- `pidbg` debug type with launch configuration for host/username/key or password auth.
- Deploy-and-attach workflow via an external debug adapter (`pidbg-adapter.exe`).
- Status bar indicator for connection state.
- `PiDbg: Connect to Device` and `PiDbg: Show Output` commands.
